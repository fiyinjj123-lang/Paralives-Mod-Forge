## 🌟 What Is This Project?

**Paralives Architect's Atelier** is an independent, open-source companion suite for Paralives players who believe that construction should feel like play, not paperwork. It began as a small experiment — a single toggle that let builders stop worrying about budget ceilings — and grew into a modular atelier of tools covering economy flow, structural previews, layout assistance, and quality-of-life polish.

The name is intentional. An *atelier* is not a factory; it is a studio where craft happens slowly and deliberately. That is the spirit here. The suite does not bulldoze the game's design language — it amplifies it. Every module is built to feel like a natural extension of the interface you already know, not a foreign overlay bolted on top.

This repository is the **public home** of the project: documentation, issue tracking, release notes, translation coordination, and the long-running conversation between builders, modders, and tinkerers.

## 🧩 Module Breakdown

The atelier is organized into distinct modules, each independently toggleable. This modularity is deliberate: you should never be forced to accept a feature you do not want.

### 🏦 Economy Module

The Economy Module governs resource flow. Rather than a blunt, all-or-nothing switch, it offers a gradient of presets — from "cautious cushion" to "unlimited studio budget." Builders who want a light safety net can enable a modest buffer; those who want total creative latitude can open the tap entirely.

### 🏗️ Construction Module

This module focuses on the building process itself. Blueprint previews, ghost placement, and structural validation help you avoid the heartbreak of a misplaced load-bearing element discovered three hours later.

### 🎨 Aesthetic Module

Textures, palettes, lighting presets, and decorative clusters. This module is about making the finished result *feel* right, not just function correctly.

### 🗂️ Workflow Module

Keyboard shortcuts, macro bindings, quick-save slots, and session snapshots. For power users who build at the speed of thought.

## 🖥️ Responsive Interface Philosophy

The atelier's interface adapts to whatever canvas you build on. Ultra-wide monitors gain expanded toolbars; laptops receive compact, icon-first layouts; handheld setups get touch-friendly hit areas and gesture support. The guiding principle is simple: **your tools should expand and contract with your screen, never fight it.**

Panels can be docked, floated, or collapsed. The layout remembers your preferences across sessions. Dark, light, and high-contrast themes ship in the box, with accent color customization for those who like their workspace to match their aesthetic.

## ⚡ Getting the Suite Running

We believe setup should be as calm as the building process itself. Here is the general shape of it:

1. **Check Prerequisites** — Confirm your game version matches the compatibility table in the releases section.
2. **Obtain the Package** — Retrieve the latest distribution through the official release channel indicated by the maintainers.
3. **Place Files** — Drop the suite's directory into the designated companion folder your game already recognizes.
4. **Launch and Confirm** — Start Paralives, open the atelier panel from the main interface, and verify the version badge.
5. **Configure to Taste** — Visit the Unified Settings Hub and enable only the modules you want.
6. **Explore and Build** — That is it. Go make something beautiful.

Detailed, screen-by-screen walkthroughs live in the `docs/` directory of this repository.

## 🔐 Safety, Transparency, and Fair Play

This project takes integrity seriously. The suite:

- Contains **no obfuscated binaries** — every script is human-readable.
- Performs **no network calls** during normal operation.
- Collects **no telemetry**, anonymous or otherwise.
- Is **fully auditable** by anyone with a text editor and patience.
- Respects the **single-player nature** of the experience, focusing exclusively on private creative use.

We believe abundance in a personal sandbox is a legitimate design choice, comparable to a photographer adjusting exposure before a shoot. The suite is built for personal, offline creative play.
